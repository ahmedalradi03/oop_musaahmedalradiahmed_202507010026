2.1. Why are the variables declared as private?
Variables are declared as private to achieve encapsulation (data hiding). This protects sensitive student data (like ID and CGPA) from unauthorized or accidental direct modification from outside the Student class.

2.2. What happens if the variables are declared public?
If the variables are declared public, any external class can directly access and modify them (e.g., student.cgpa = 5.0;) without any restrictions or validation, compromising data security and integrity.

2.3. Why do we use getters and setters?
Getters and setters provide controlled, secure access to private variables. Getters allow external classes to safely read the values, while setters allow controlled updates—enabling you to add validation logic (such as ensuring a CGPA is between 0.0 and 4.0) before saving the data.
